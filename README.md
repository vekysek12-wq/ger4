### О проекте

Консольное приложение .NET. В проекте живут герои гильдии и склад товаров
(личная тема). По ходу курса проект растёт: от отдельных переменных — к
коллекциям, от повторяющегося вывода — к циклам, от голых полей — к классам
с защитой состояния.

### Личный проект

- `Hero.cs` - класс героя: имя, здоровье, уровень, опыт; методы `TakeDamage`,
  `Heal`, `GainExperience`, `IsAlive`, `GetInfo`.
- `Guild.cs` - класс гильдии: название и список участников (`List<Hero>`).
- `Probe.cs` - отдельный файл для учебных проб; в основной сценарий не
  попадает (вызов `Probe.Run()` закомментирован).
- `Program.cs` - основной сценарий: герои, гильдия, перекличка, подсчёты,
  плюс блок личного проекта (склад товаров).
- `Product.cs` - личный класс: товар с названием, количеством и ценой;
  методы `Restock`, `Sell`, `GetTotalValue`.
