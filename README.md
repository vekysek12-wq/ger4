### Исправление ошибок (Этап 9)
1. **Слишком открытое свойство:** `public int Health { get; set; }` разрешало менять здоровье снаружи. Исправлено на `public int Health { get; private set; }` - прямое присваивание из `Program.cs` теперь вызывает ошибку компиляции.
2. **Несохранённый результат Trim():** вызов `value.Trim();` без присваивания не менял строку `value`. Исправлено на `_name = value.Trim();` - имя `"   Александр   "` очищается до `[Александр]`.

### Ответы на вопросы (Этап 12)
1. **Запрет внешней записи и проверка числа:** `private set` запрещает менять свойство извне класса, но не проверяет само значение. Допустимость чисел проверяется внутри `Hero`: в конструкторе при создании объекта и в методах `TakeDamage`, `Heal` при изменении.
2. **Связь `Name = name;`:** конструктор передаёт параметр `name` в сеттер свойства `Name`, где оно становится доступным через ключевое слово `value`, очищается от пробелов и записывается в закрытое поле `_name`.
3. **Проверка инварианта `0 <= Health <= MaxHealth`:** при передаче `-100` в конструктор здоровье стало `0/100`, при `5000` - `200/200`, лечение на `5000` у Александра остановилось на `150/150`, а урон на `5000` остановился на `0`.
